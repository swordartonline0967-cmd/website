# ゲームソフト大全（仮称）

ファミコンから Nintendo Switch 2・PS5 まで、**日本で発売された家庭用ゲームソフトを調べられるデータベースサイト**です。
将来アフィリエイト（Amazon・楽天・Yahoo!ショッピング・駿河屋など）で収益化できるように作ってあります。

- 掲載ソフト数: **約49,000本**（40機種・約5,900メーカー）
- 機種別・発売年別・メーカー別・ジャンル別の一覧、今日は何の日、発売予定、ソフト検索
- 各ソフトのページに「ショップで探す」ボタン（アフィリエイトIDを設定すると広告リンクになります）
- スマホ対応・検索エンジン対策（構造化データ、サイトマップ）済み
- データは Wikipedia / Wikidata から**毎週自動で更新**

> サイト名「ゲームソフト大全」は仮の名前です。`src/config/site.ts` で変更できます。

## サイトのページ構成

| URL | ページ |
| --- | --- |
| `/` | トップページ（検索、今日は何の日、まもなく発売、機種一覧など） |
| `/platforms/` | ハード（ゲーム機）一覧 |
| `/platforms/fc/` | 機種ごとのページ（例: ファミコン） |
| `/platforms/fc/1985/` | 機種×発売年のソフト一覧 |
| `/games/fc-66/` | ソフトの詳細ページ（例: スーパーマリオブラザーズ） |
| `/makers/` `/makers/2/` | メーカー一覧・メーカーごとのソフト一覧 |
| `/genres/` `/genres/rpg/` `/genres/rpg/sfc/` | ジャンル別 |
| `/years/` `/years/1998/` | 発売年別 |
| `/calendar/` `/calendar/09-27/` | 今日は何の日（その日に発売されたゲーム） |
| `/upcoming/` | 発売予定のソフト |
| `/search/` | ソフト検索（略称「ドラクエ」「FF7」「スマブラ」なども対応） |
| `/about/` `/privacy/` `/contact/` | このサイトについて・プライバシーポリシー・お問い合わせ |

## フォルダ構成（どこに何があるか）

```
data/                  ← サイトのデータ（ここを直すと内容が変わる）
  platforms.json       ← ゲーム機の情報（発売日・価格・説明文など）
  games/fc.json など   ← 機種ごとのソフト一覧（1行＝1本）
  makers.json          ← メーカー一覧（メーカーページのID）
  genres.json          ← ジャンルの一覧と説明
src/
  config/site.ts       ← サイト名・URL・お問い合わせ・Google設定
  config/affiliate.ts  ← アフィリエイトID（ここにIDを貼る）
  pages/               ← 各ページの作り（URLと対応）
  components/          ← ヘッダー・フッター・ショップボタンなどの部品
  styles/global.css    ← デザイン（色など）
scripts/import/        ← Wikipedia / Wikidata からデータを取り込むプログラム
docs/                  ← 説明書
.github/workflows/     ← 自動公開・自動更新の設定（GitHub Actions）
wrangler.jsonc         ← Cloudflare で公開する場合の設定
```

## パソコンで動かす場合（任意・上級者向け）

公開や更新は GitHub 上で自動で行われるので、**パソコンでの作業は必須ではありません。**
自分のパソコンで確認したい場合は、[Node.js](https://nodejs.org/ja)（22以上）を入れてから次を実行します。

```bash
npm install          # 最初の1回だけ（必要な部品を入れる）
npm run dev          # 開発用サーバーを起動 → http://localhost:4321 で表示確認
npm run build        # 公開用のファイルを dist フォルダに作る（約2分）
npm run data:import  # Wikipedia / Wikidata から最新データを取り込む（約10分）
npm run data:validate # データの書き方に間違いがないかチェック
```

## データの出典とライセンス

- ソフト一覧（タイトル・日本での発売日・発売元・備考など）は、Wikipedia日本語版の各「ゲームタイトル一覧」記事をもとにしています（[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)）。そのため `data/games/` のデータも CC BY-SA 4.0 で扱ってください。サイト上では各ページに出典リンクを表示しています。
- ジャンル・開発元の一部は [Wikidata](https://www.wikidata.org/)（CC0）を利用しています。
- ゲーム機の説明文・サイトのプログラムはこのサイト独自のものです。
- ゲーム機・ゲームソフトの名称は各社の商標または登録商標です。
