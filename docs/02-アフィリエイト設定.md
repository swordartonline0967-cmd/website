# 02. アフィリエイトの設定

サイトの各ページには「**Amazonで探す**」「**楽天市場で探す**」「**Yahoo!ショッピングで探す**」「**駿河屋で探す**」のボタンがあります。
いまは普通の検索リンクですが、アフィリエイトに登録して **ID を1か所に貼るだけ** で、広告リンク（購入されると報酬が入るリンク）に切り替わります。

---

## 仕組みのおさらい

- 訪問者がボタンからショップに移動 → そのショップで商品を購入 → 売上の数％が報酬として入ります
- ボタンは「タイトル＋機種名」でショップを検索するリンクになっています（例：「スーパーマリオブラザーズ ファミコン」）
- 2009年以前に発売されたソフト・ゲーム機は、中古に強い **駿河屋** のボタンが先頭に来るようにしています

---

## おすすめの登録順（初心者向け）

| 順番 | サービス | 難易度 | ポイント |
| --- | --- | --- | --- |
| ① | [楽天アフィリエイト](https://affiliate.rakuten.co.jp/) | ★☆☆ | 楽天会員ならすぐ使える（審査なし） |
| ② | [もしもアフィリエイト](https://af.moshimo.com/) | ★☆☆ | Amazon・楽天・Yahoo! をまとめて扱える。Amazon の審査が比較的通りやすい |
| ③ | [バリューコマース](https://www.valuecommerce.ne.jp/) | ★★☆ | Yahoo!ショッピングの報酬を直接受け取れる |
| ④ | [駿河屋アフィリエイト](https://affiliate.suruga-ya.jp/) | ★★☆ | レトロゲーム・中古ゲームに強い。このサイトと相性抜群 |
| ⑤ | [Amazonアソシエイト](https://affiliate.amazon.co.jp/) | ★★★ | 登録後180日以内に3件の売上が必要（それまでは仮登録） |

> 💡 Amazon は「もしもアフィリエイト経由」か「Amazonアソシエイト直接」の**どちらか一方**で設定すればOKです。
> 最初は審査が通りやすい「もしも経由」で始め、実績ができてから直接契約に切り替える人が多いです。

## 各サービスで「ID」を確認する方法

登録の手続きは各サービスの画面の案内に従ってください。サイトのURLを聞かれたら、公開したURL（[01-公開手順](01-公開手順.md) の手順4）を入力します。

### ① 楽天アフィリエイト → 「アフィリエイトID」

1. [楽天アフィリエイト](https://affiliate.rakuten.co.jp/) に楽天会員でログインし、利用を開始します
2. 何か1つ商品を検索して「**リンク作成**」ボタンを押し、表示されたリンク（HTMLコード）を見ます
3. `https://hb.afl.rakuten.co.jp/ichiba/1a2b3c4d.5e6f7a8b.1a2b3c4d.5e6f7a8b/?pc=…` のような部分の、
   **点（.）で区切られた長い英数字**（例: `1a2b3c4d.5e6f7a8b.1a2b3c4d.5e6f7a8b`）がアフィリエイトIDです

### ② もしもアフィリエイト → 各ショップの「a_id」

1. [もしもアフィリエイト](https://af.moshimo.com/) に無料登録し、サイトを登録します
2. 「プロモーション検索」で「**Amazon**」「**楽天市場**」「**Yahoo!ショッピング**」を探し、それぞれ「**提携申請**」します
3. 提携が承認されたら、各プロモーションの「**どこでもリンク**」などでリンクを作ると、
   リンクの中に `a_id=1234567` のような部分があります。この **数字** が a_id です
   - ⚠ a_id は **ショップごとに違う番号** です。Amazon用・楽天用・Yahoo!用をそれぞれ控えてください
   - ⚠ 管理画面に表示される「会員ID（ユーザーID）」とは **別の番号** です。リンクに使うのは a_id です

### ③ バリューコマース → 「sid」と「pid」

1. [バリューコマース](https://www.valuecommerce.ne.jp/) に無料登録し、サイトの審査を受けます
2. 広告主検索で「**Yahoo!ショッピング**」を探して提携申請します
3. 提携後、Yahoo!ショッピングのテキストリンク（または MyLink）を作ると、
   リンクの中に `sid=3712345&pid=887654321` のような部分があります。この **sid の数字** と **pid の数字** を控えます

### ④ 駿河屋アフィリエイト → 「ユーザーID」

1. [駿河屋アフィリエイト](https://affiliate.suruga-ya.jp/) に登録し、審査を受けます
2. 承認後にリンクを作ると、`af_jump.php?user_id=1234&goods_url=…` のような部分があります。この **user_id の数字** を控えます

### ⑤ Amazonアソシエイト → 「トラッキングID」

1. [Amazonアソシエイト](https://affiliate.amazon.co.jp/) に Amazon アカウントで申し込みます（サイトのURLを登録）
2. 登録の途中で作る「**トラッキングID**」（`あなたの名前-22` のように **末尾が -22**）を控えます
3. ⚠ 申し込みから **180日以内に3件以上の売上** がないと、承認されずに終了します（再申し込みは可能）

## ID をサイトに設定する（GitHub の画面で直接編集）

1. ブラウザで次のファイルを開きます
   **https://github.com/swordartonline0967-cmd/website/blob/main/src/config/affiliate.ts**
2. 右上の **鉛筆マーク（✏️ Edit this file）** をクリックします
3. 控えたIDを、該当する行の `''`（シングルクォート2つ）の**間**に貼り付けます

   ```ts
   // 変更前
   trackingId: '',
   // 変更後（例）
   trackingId: 'yourname-22',
   ```

   | 貼る場所 | 貼るもの |
   | --- | --- |
   | `amazon` の `trackingId` | AmazonアソシエイトのトラッキングID（例 `yourname-22`） |
   | `rakuten` の `affiliateId` | 楽天のアフィリエイトID（例 `1a2b3c4d.5e6f7a8b.1a2b3c4d.5e6f7a8b`） |
   | `yahoo` の `valueCommerceSid` / `valueCommercePid` | バリューコマースの sid / pid |
   | `surugaya` の `userId` | 駿河屋のユーザーID |
   | `moshimo` の `amazonAid` / `rakutenAid` / `yahooAid` | もしもアフィリエイトの各ショップの a_id |

4. 右上の緑色の「**Commit changes...**」（変更を保存）→ もう一度「**Commit changes**」をクリック
5. 約10分で自動的にサイトに反映されます

> ⚠ `'`（クォート）や `,`（カンマ）を消さないように注意してください。万一書き間違えてもサイトは前の状態のまま残るので壊れません。
> 不安なときは Claude に「楽天のアフィリエイトIDを 〇〇 に設定して」と頼むのが確実です。

### 設定できたか確認する方法

公開サイトで適当なソフトのページを開き、「楽天市場で探す」などのボタンを押して、移動先のURLに自分のIDが含まれていればOKです。

## 法律・規約への対応（自動で行われます）

IDを1つでも設定すると、サイトに次の表示が**自動的に**追加されます。

- ページ上部に「**本ページはプロモーション（アフィリエイト広告）を含みます**」
  （2023年10月から施行された **景品表示法のステルスマーケティング規制** への対応）
- ショップボタンの枠に「**PR**」ラベル、リンクに `rel="sponsored"`（Googleの推奨設定）
- Amazonアソシエイトのトラッキングを設定すると、フッターに規約で定められた文言
  「Amazonのアソシエイトとして、（サイト名）は適格販売により収入を得ています。」

また、[プライバシーポリシー](../src/pages/privacy.astro) にアフィリエイトとCookieについての説明を記載済みです。
使わないサービスがある場合や、内容を変えたい場合は Claude に相談してください。

## 審査に通りやすくするコツ

- **お問い合わせ先** を用意する（→ [04-サイトのカスタマイズ](04-サイトのカスタマイズ.md) の「お問い合わせフォーム」）
- **独自ドメイン** を使う（→ [01-公開手順](01-公開手順.md) の「独自ドメイン」）
- **オリジナルの文章** を少しずつ増やす：このサイトのソフト情報は Wikipedia が元なので、
  ソフトの紹介文・おすすめ記事・特集ページなどの独自コンテンツがあると、審査にも検索順位にも有利です
- 自分のリンクから自分で購入するのは規約違反になるサービスが多いので避けてください
