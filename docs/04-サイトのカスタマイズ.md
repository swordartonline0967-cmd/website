# 04. サイトのカスタマイズ

設定はほぼすべて **`src/config/site.ts`** の1ファイルにまとまっています。
GitHub でファイルを開き、**鉛筆マーク（✏️）** で編集 →「**Commit changes**」で保存すると、約10分でサイトに反映されます。

---

## サイト名・説明文を変える

`src/config/site.ts` の次の部分を書き換えます。

```ts
name: 'ゲームソフト大全',            // サイト名（ロゴ・タイトルに表示）
tagline: '家庭用ゲームのソフト・ハード情報データベース',  // ロゴの下の説明
description: 'ファミコンから…',      // 検索結果に出るサイトの説明文
operator: 'ゲームソフト大全 運営事務局', // 運営者名（プライバシーポリシー等に表示）
```

> サイト名を変えたら、SNS共有用の画像（`public/og-image.png`）も作り直しましょう。
> Claude に「OGP画像を新しいサイト名で作り直して」と頼めばOKです（→ `scripts/og-image/README.md`）。

## お問い合わせフォームを作る（Googleフォーム・無料）

アフィリエイトの審査では「連絡先があるか」が見られることが多いので、早めに用意しましょう。

1. [Googleフォーム](https://docs.google.com/forms/) を開き、Googleアカウントでログイン
2. 「空白のフォーム」を作成し、タイトルを「お問い合わせ」にする
3. 質問を3つ作る
   - 「お名前（ニックネーム可）」… 記述式
   - 「メールアドレス（返信をご希望の場合）」… 記述式
   - 「お問い合わせ内容」… 段落（必須にする）
4. 右上の「**送信**」→ リンクのアイコン（🔗）→ 表示されたURLを「コピー」
5. `src/config/site.ts` の `contactFormUrl: ''` の `''` の間に貼り付けて保存
   ```ts
   contactFormUrl: 'https://docs.google.com/forms/d/e/xxxxxxxx/viewform',
   ```
6. 回答が届いたらメールで知らせてもらうには：フォームの「回答」タブ →「⋮」→「新しい回答についてのメール通知を受け取る」

## Google に登録する（Search Console・おすすめ）

Google の検索結果に早く・正しく載せるための無料ツールです。

1. [Google Search Console](https://search.google.com/search-console) を開き、「プロパティを追加」
2. 「**URL プレフィックス**」を選び、公開サイトのURL（例: `https://swordartonline0967-cmd.github.io/website/`）を入力
3. 確認方法で「**HTML タグ**」を選ぶと `<meta name="google-site-verification" content="abcd1234..." />` が表示されるので、
   **content="…" の中身だけ** をコピー
4. `src/config/site.ts` の `googleSiteVerification: ''` の `''` の間に貼り付けて保存し、10分ほど待つ
5. Search Console に戻って「**確認**」をクリック
6. 左メニューの「**サイトマップ**」で `sitemap-index.xml` と入力して「送信」

## アクセス数を調べる（Googleアナリティクス・任意）

1. [Googleアナリティクス](https://analytics.google.com/) でアカウントとプロパティを作成
2. 「データストリーム」で「ウェブ」を選び、サイトのURLを登録
3. 表示される「**測定ID**」（`G-` から始まる文字列）をコピー
4. `src/config/site.ts` の `googleAnalyticsId: ''` に貼り付けて保存

## X（旧Twitter）のアカウント

`src/config/site.ts` の `xAccount: ''` に、@を除いたアカウント名を入れると、共有時の表示に使われます。

## 色を変える

`src/styles/global.css` の先頭にある `:root { … }` の色を書き換えます。

| 変数 | 使われている場所 | 初期値 |
| --- | --- | --- |
| `--primary` | ボタン・強調色 | `#d9143a`（赤） |
| `--header-bg` | ヘッダー・フッターの背景 | `#16181d`（黒に近い紺） |
| `--link` | リンクの文字色 | `#0a5bc4`（青） |
| `--bg` | ページの背景 | `#f4f5f7`（薄いグレー） |

※ スマホやパソコンが「ダークモード」のときは、`@media (prefers-color-scheme: dark)` の中の色が使われます。
