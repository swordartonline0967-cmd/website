# 05. 発売日順クリア企画の記録を更新する

サイトには「**発売日順クリア企画**」のページ（`/playlog/`）があり、遊んだソフトの記録とYouTubeの動画が表示されます。
記録は **Google スプレッドシート** に書くだけで、**1時間ごとに自動でサイトに反映** されます。

- ソフトのページ：企画の記録（クリア・挑戦中など）とプレイ動画
- ハードのページ：その機種の進み具合と「次に遊ぶソフト」（発売日順で自動表示）
- 各一覧：企画で遊んだソフトに「クリア」などの印
- トップページ：企画の現在地

> 💡 最初の記録は、YouTubeチャンネルの動画タイトル（「#12 [FC/NES] タイトル .END」の形）から自動で作りました（クリア412本・企画外の動画33本）。

---

## 最初の1回だけ：スプレッドシートを作ってサイトとつなぐ（約15分）

### 1. スプレッドシートを作る

1. Claude から受け取った **`プレイ記録_初期データ.csv`** をパソコンに保存します
2. [Google スプレッドシート](https://docs.google.com/spreadsheets/) を開き、「**空白のスプレッドシート**」をクリックします
3. 左上の「無題のスプレッドシート」をクリックして、名前を「発売日順クリア企画 記録」などに変えます
4. メニューの「**ファイル**」→「**インポート**」→「**アップロード**」タブ →「参照」で、保存したCSVファイルを選びます
5. 次のように選んで「**データをインポート**」をクリックします
   - インポート場所：**現在のシートを置換する**
   - 区切り文字の種類：**自動的に検出する**

これで、1行＝1本のソフトの表ができます。

### 2. スプレッドシートを「ウェブに公開」する

サイトが記録を読み込めるように、CSV形式で公開します。

1. メニューの「**ファイル**」→「**共有**」→「**ウェブに公開**」をクリックします
2. 「リンク」タブで、左のプルダウンを **記録のシート（シート1 など）**、右のプルダウンを「**カンマ区切り形式（.csv）**」にします
3. 「**公開**」→ 確認画面で「**OK**」をクリックします
4. 表示された **URL をコピー** します（`https://docs.google.com/spreadsheets/d/e/…/pub?…output=csv` のような長いURL）

> ⚠ 「ウェブに公開」すると、URLを知っている人は誰でも表の中身を見られます。個人的なメモなどは書かないでください。
> （「公開されたコンテンツと設定」の「変更が加えられたときに自動的に再公開する」はオンのままにしてください）

### 3. URL をサイトの設定に貼る

1. ブラウザで次のファイルを開きます
   **https://github.com/swordartonline0967-cmd/website/blob/main/src/config/playlog.ts**
2. 右上の **鉛筆マーク（✏️ Edit this file）** をクリックします
3. `sheetCsvUrl: '',` の `''`（シングルクォート2つ）の **間** に、コピーしたURLを貼り付けます
   ```ts
   sheetCsvUrl: 'https://docs.google.com/spreadsheets/d/e/xxxxxxxx/pub?gid=0&single=true&output=csv',
   ```
4. 右上の緑色の「**Commit changes...**」→ もう一度「**Commit changes**」をクリックします

これで設定は完了です。以後は1時間ごとにスプレッドシートが読み込まれます。

> 不安なときは、URL を Claude に送って「プレイ記録のスプレッドシートを設定して」と頼んでもOKです。

## ふだんの更新：スプレッドシートに1行書くだけ

ソフトを遊び始めたら（またはクリアしたら）、表のいちばん下に1行追加します。

| 列 | 書くこと | 例 |
| --- | --- | --- |
| 機種 | 動画タイトルと同じ書き方でOK | `FC/NES`、`SFC`、`PS1`、`PS4`、`Switch` など |
| 番号 | 企画での通し番号（機種ごと） | `101` |
| タイトル | ソフトの名前（このサイトの表記に近いほど確実） | `サーカスチャーリー` |
| 状態 | 次の4つのどれか | `クリア` / `挑戦中` / `保留` / `企画外` |
| クリア日 | 分かれば（空欄でもOK） | `2026/10/04` |
| 動画URL | YouTubeの動画のURL（複数あるときは改行かスペースで区切る） | `https://www.youtube.com/watch?v=…` |
| ひとこと | 感想など（空欄でもOK。ソフトのページに表示されます） | `ジャンプの操作に慣れるまで苦戦した` |
| ID | 空欄でOK（下の「うまく結び付かないとき」を参照） | `fc-101` |
| メモ | 自分用のメモ（サイトには表示されません） | |

- **状態の意味**：`クリア`＝クリアした、`挑戦中`＝いま遊んでいる、`保留`＝途中で止めている、`企画外`＝企画とは別に遊んだ動画
- 状態が空欄の行は「挑戦中」として扱います
- セルの中で改行するには、Windows は **Ctrl + Enter**（または Alt + Enter）、Mac は **⌘ + Enter** を押します
- 行の順番は自由です。同じソフトの行が2つあるときは、1つにまとめて表示します
- **すぐに反映したいとき**：GitHub の「▶ Actions」→ 左の「**プレイ記録を取り込む（スプレッドシート）**」→「**Run workflow**」→ 緑の「Run workflow」。約5〜10分でサイトに反映されます

## うまく結び付かないとき

タイトルの書き方がサイトと違いすぎると、どのソフトか分からず表示されません。次のページで確認できます。

**https://swordartonline0967-cmd.github.io/website/playlog/check/**（照合結果のページ。検索エンジンには表示されません）

直し方：その行の「**ID**」の列に、ソフトのIDを入れます。IDは、このサイトのソフトのページのURLで
`/games/` の後ろにある部分です（例：`…/games/fc-66/` なら `fc-66`）。IDが入っている行は、タイトルより優先されます。

## そのほかの設定（src/config/playlog.ts）

| 項目 | 内容 |
| --- | --- |
| `name` / `navLabel` | 企画の名前と、メニューに出す短い名前 |
| `intro` | 企画ページの最初に表示する紹介文 |
| `youtubeName` / `youtubeUrl` | YouTubeチャンネルの名前とURL |
| `digitalOnlyPlatforms` | ダウンロード専用ソフトも対象にする機種（例外）。いまは `'switch2'` |

## 安全装置

- スプレッドシートの記録が **前回の半分未満に減った** ときは、行を消してしまった可能性があるため **取り込みを止めます**（サイトは前の状態のまま）
  - 本当に減らした場合：「Run workflow」で「**記録が大きく減っていても保存する**」にチェックを入れて実行します
- スプレッドシートを開けなかったとき（公開をやめた、URLが違う など）も、取り込みを止めてサイトは前の状態のままになります。GitHub から失敗のお知らせメールが届きます
