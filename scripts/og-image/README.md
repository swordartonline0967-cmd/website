# SNS共有用画像（OGP画像）の作り方

`public/og-image.png` は、X（旧Twitter）やLINEなどでサイトのURLが共有されたときに表示される画像（1200×630ピクセル）です。

サイト名を変えたときは、この画像も作り直してください。

- いちばん簡単な方法: Claude に「OGP画像をサイト名『◯◯』で作り直して」と頼む
- 自分で作る場合: `og.html` の文字を書き換えてブラウザで開き、1200×630の範囲をスクリーンショットして `public/og-image.png` に上書き保存
- Canva などの画像作成サービスで 1200×630 の画像を作って置き換えてもOKです
